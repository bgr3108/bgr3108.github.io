# Landing de Kilonom para GitHub Pages

Esta carpeta contiene los archivos de la nueva página raíz de `bgr3108.github.io`:

- `index.html`: landing responsive y el contenido SEO básico.
- `styles.css`: estilos sin frameworks ni dependencias externas.
- `favicon.png`: icono de la aplicación ya presente en el proyecto Android.

## Publicación

Copia estos tres archivos en la raíz del repositorio `bgr3108.github.io`, reemplazando solamente la anterior página raíz y sus estilos si existen. No elimines ni sobrescribas `app-ads.txt` y conserva la carpeta `CocheHibrido/privacy/` tal como está.

## Activar Google Play

En `index.html`, busca `data-play-url=""` en el enlace con `id="google-play"` y pega la URL pública confirmada de Google Play. Al cargar la página, el botón quedará activo de forma automática y desaparecerá el aviso de revisión.
